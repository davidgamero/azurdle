# Third-party materials

## Microsoft Azure service icons

Icons in `public/icons/` (except `generic.svg`, which is original) are published
by Microsoft. They are displayed to identify and teach Azure services.

- [Azure architecture icons and usage terms](https://learn.microsoft.com/en-us/azure/architecture/icons/)
- [Official icon archive, version 25](https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V25.zip)
- [Microsoft Azure documentation hub](https://github.com/MicrosoftDocs/azure-docs/blob/main/articles/index.yml)
- [Azure documentation repository license](https://github.com/MicrosoftDocs/azure-docs/blob/main/LICENSE)
- [Microsoft trademark guidance](https://www.microsoft.com/legal/intellectualproperty/trademarks)

The architecture icon terms permit use in architectural diagrams, training
materials, and documentation. These assets are not covered by Azurdle's MIT
license. Each imported icon's source is recorded in `src/data/catalog.json`.
Icons are displayed unmodified. Microsoft retains ownership of its trademarks.

## Product names and descriptions

Product names, summaries, links, and categories are scraped from the
[Microsoft Azure product directory](https://azure.microsoft.com/en-us/products/).
Summaries are reproduced for educational service-identification clues, with
links to the original product pages. They are not original Azurdle content and
are not relicensed under the MIT license. The catalog records its retrieval
date and source URLs.

## Original artwork

Azurdle's app icon, desktop shortcut illustrations, generic service fallback,
and CSS landscape are original. No Windows wallpaper or Windows system assets
are distributed. The interface is inspired by the Windows XP desktop.

Azurdle is an independent educational fan project, not affiliated with or
endorsed by Microsoft.
